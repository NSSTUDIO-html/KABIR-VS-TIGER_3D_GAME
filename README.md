⚔️ KABIR VS TIGER — 3D ACTION GAME

A browser-based 3D action and combat game featuring cinematic environments, weapon-based battles, enemy bases, and immersive third-person gameplay.

Developed by NS STUDIO

---

🎮 About the Game

Kabir vs Tiger is a frontend-only 3D web game project designed to run directly in a modern web browser.

The project focuses on 3D character models, real-time combat, weapon systems, enemy AI, interactive environments, and responsive game controls.

The goal is to create an action-packed gaming experience using web technologies without requiring a dedicated backend server.

🕹️ Game Modes

1. 🤖 AI Combat Mode

- Fight against an AI-controlled opponent.
- Play as Kabir or Tiger.
- Implement different weapons and combat styles.
- Add health bars, damage systems, and combat animations.
- Develop AI movement, attacks, and defensive behavior.
- Create a one-on-one battle arena.

2. 👥 Two-Player Local Co-op Mode

- Play with two heroes on the same device.
- Complete combat missions together.
- Explore enemy military bases.
- Fight enemy soldiers and hostile NPCs.
- Use weapons and teamwork to complete objectives.
- Locate and defeat the enemy commander.

Local co-op is planned for shared-device gameplay. It does not require online multiplayer or a network server.

🚀 Run the Game

Option 1: GitHub Pages

1. Upload the project files to a GitHub repository.
2. Open the repository's Settings.
3. Select Pages.
4. Choose the deployment branch and root folder.
5. Save and open the published website.

Option 2: Run Locally

1. Download or clone the repository.
2. Open the project in a code editor.
3. Start a local development server if required by JavaScript modules or asset loading.
4. Open the local URL in a modern browser.

📱 Platform Support

- Android browsers
- Desktop browsers
- Laptop browsers
- Other modern browsers supporting WebGL

🌐 Deployment

Target platform: GitHub Pages

The game is designed as a static frontend project.

- No backend server planned.
- No online multiplayer planned.
- No database required for the core game.
- No network server required for local two-player gameplay.

Online accounts, cloud saves, or internet multiplayer would require additional infrastructure if introduced later.
